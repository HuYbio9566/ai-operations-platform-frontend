# AI 运营驾驶舱前端

当前发布版本：`v1.1.0`

Vue 3 + Vite 实现的 AI 运营数据看板界面。

在线演示：<https://huybio9566.github.io/ai-operations-platform-frontend/>

## 本地运行

`npm ci`
`npm run dev`

## 构建

`npm run build`
`npm run build:demo`

GitHub Pages 使用 `build:demo` 构建，演示页面采用脱敏模拟数据，不连接实时后端。正式内网部署仍使用原有 Django API 与公司 SSO。内部报告素材未随仓库公开。
